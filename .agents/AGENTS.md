# Project Rules & Guidelines for Streamline

## Design & Responsive Web Principles

1. **Dynamic & Alive UI**:
   - Every interface must feel dynamic, responsive, and alive. Use subtle animations, micro-interactions, real-time data visual indicators (e.g. glowing status badges, pulsing telemetry, active streams), hover states, and smooth transitions.
   - Avoid static placeholders or flat minimal designs. Use modern enterprise aesthetics (Tailwind CSS, high-contrast dark enterprise themes, clean card layouts, crisp typography).

2. **Strict Responsive Web Design (RWD)**:
   - All layouts must adapt fluidly across screen sizes (mobile `<640px`, tablet `640px–1024px`, desktop `>1024px`, wide displays).
   - Use mobile-first flexbox and grid structures (`flex-col lg:flex-row`, `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`).
   - Ensure touch targets, spacing, text scaling, and overflow handling work seamlessly on all devices without horizontal scrolling issues.
